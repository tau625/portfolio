# 作品集网页 · 建站（web-design-engineer）+ 部署（GitHub Pages）方案

## 一、建站阶段 —— 按 web-design-engineer 技能的工作流执行

技能位于 `D:\12_Agents\Skills\web-design-engineer`（不在本会话已注册技能列表中，我会直接读取其 SKILL.md 并严格按其流程执行）：

1. **收集信息**：向你要基本信息（姓名/职业定位、代表作品 2~4 个、联系方式、希望给谁看）；真实素材缺失处按技能的占位符规范处理（`[image]`、`[链接]`），绝不编造数据和假logo。
2. **设计方向（Design Direction Advisor）**：从风格配方库中挑 3 个差异明显的方向供你选（如：极简高级感 `aesop`/`muji-kenya-hara`、开发者工具感 `linear`/`vercel-mesh`、温暖亲和 `stripe-press`/`mailchimp-freddie`），每个附适用理由和视觉特征。
3. **声明设计系统**（Checkpoint 1）：选定方向后，宣读色板、字体、间距、圆角、阴影、动效规则，经你确认再动手。
4. **v0 草稿**（Checkpoint 2）：先出核心布局 + 占位符的可视草稿，你把关方向后再完整构建。
5. **完整构建**：纯 HTML + CSS + JS（无需构建工具，GitHub Pages 直接可用），含响应式、hover/focus 状态、流畅动效。
6. **自检**：按技能的 Pre-delivery Checklist 逐项核对（无 AI 套路配色/emoji 滥用、无假数据、交互状态完整等），并做 5 维度设计自评。

## 二、部署阶段 —— GitHub Pages（已装 github 技能辅助）

1. 检测本机 `git` / `gh` 环境（缺什么给安装/登录指引）
2. 在工作目录 `git init` + 首次提交
3. 创建 GitHub 仓库并推送（gh 已登录则我直接建仓推送；否则给你网页端操作清单，一步步指导）
4. 指导开启 Settings → Pages → main 分支，1~2 分钟后站点上线（`用户名.github.io/仓库名`）

## 三、验证与交付

- 上线前后用 browser-use 打开页面实际访问、截图验证排版与交互
- 交付使用说明：如何改内容、如何发布更新（commit → push 自动重新部署）

后续可选：自定义域名、Vercel 备选、国内访问优化——上线后需要再做。
